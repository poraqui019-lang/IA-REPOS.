# Capabilities

## Disponíveis

| Capacidade | Uso preferencial |
| --- | --- |
| GitHub | código-fonte, issues, pull requests e automação de repositório |
| Vercel | deploy e hospedagem de aplicações web |
| Supabase | banco de dados, autenticação, storage e recursos relacionados |
| Figma | referência e inspeção de design, quando o acesso for fornecido |

## Princípios

- Verifique a capability aplicável antes de introduzir uma solução nova.
- Escolha ferramentas pela adequação à tarefa, custo e manutenção.
- Peça configuração, credenciais ou acesso somente quando forem necessários.
