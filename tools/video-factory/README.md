# Video Factory

Módulo próprio para vídeos programáticos com Remotion. A composição inicial `VideoFactoryTest` gera um vídeo vertical de 1080×1920, 30 fps e 3 segundos.

## Uso

```bash
npm install
npm run studio
npm run render:test
```

O render de prova vai para `out/video-factory-test.mp4`, que é ignorado pelo Git. Coloque imagens e outros recursos em `assets/`, áudio em `assets/audio/` e novas composições reutilizáveis em `templates/`.
