# Web development

Comece inspecionando as regras locais, o stack e as capabilities disponíveis. Preserve a arquitetura, o código e o layout existentes quando a tarefa não exigir uma alteração estrutural.

Reutilize componentes, estilos e padrões do projeto antes de criar alternativas. Use Figma como referência quando houver acesso e a tarefa exigir fidelidade de design.

Teste as alterações no navegador com automação quando disponível; valide os fluxos relevantes, responsividade necessária e erros de console. Para publicação, siga a skill de deployment.
