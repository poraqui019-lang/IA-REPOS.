# Deployment

Use Vercel quando for aplicável ao projeto web. Antes do deploy, verifique o comando de build, variáveis de ambiente, configurações de domínio e o estado do repositório.

Não substitua configurações existentes sem necessidade. Separe preview de produção sempre que o fluxo do projeto permitir e evite publicar mudanças não validadas.

Valide build, deploy e fluxo principal após a publicação. Registre URL, ambiente, commit e qualquer configuração pendente.
