# MoneyPrinterTurbo

Consulte esta skill quando a tarefa pedir geração rápida de Shorts, Reels ou TikTok a partir de tema, roteiro ou palavras-chave. MoneyPrinterTurbo pode criar roteiro, selecionar materiais, gerar legendas, adicionar música e montar o vídeo final.

## Decisão

Use MoneyPrinterTurbo para automação rápida. Prefira Remotion / Video Factory quando o usuário fornecer assets que precisam ser preservados exatamente, exigir controle preciso por cena, edição quadro a quadro ou um produto que não possa ser alterado visualmente.

## Uso seguro

Trate-o como repositório externo disponível sob demanda; não copie seu código para IA-REPOS. Inspecione requisitos antes de instalar: o projeto requer Python 3.11+ e recomenda `uv`; fluxos de vídeo também podem precisar de ffmpeg e provedores externos. Não configure APIs pagas, tokens ou credenciais sem autorização explícita.

Após instalação autorizada em um diretório isolado, valide primeiro um fluxo local sem segredos. Registre bloqueios de Python, uv, ffmpeg, rede, certificado ou APIs em vez de contorná-los de forma insegura.
