# Database

Use Supabase quando ele for aplicável ao banco, autenticação, storage ou recursos relacionados. Primeiro inspecione o schema, migrações, políticas de acesso e clientes existentes.

Prefira migrações versionadas e mudanças compatíveis. Não altere dados de produção, políticas de acesso ou configuração de autenticação sem autorização explícita.

Teste a alteração com o menor conjunto representativo: migração, consultas afetadas, regras de acesso e fluxo de autenticação quando aplicável.
